How it works

  1. Shop like normal on H&M’s website.
  2. Open any product page.
  3. You see if H&M is a Certified B Corp, where that came from, and when we last checked.

More shops and brands are coming, then naughty-or-nice ratings for staff, communities and the environment.

Install it

Chrome

Until we're in the Chrome Web Store, it takes a minute by hand.

  1. Download naughty-list.zip [link] and unzip it.
  2. Paste chrome://extensions into the address bar.
  3. Switch on Developer mode (top right).
  4. Click Load unpacked and pick the unzipped folder.
  5. Click the puzzle piece in the toolbar and pin The Naughty List.

Also works in Edge, Brave and Arc. In Edge, go to edge://extensions. Chrome may remind you that a developer extension is on. That's expected until the store version arrives.

Firefox

  1. Add to Firefox [signed .xpi link].
  2. Firefox asks if you want to add The Naughty List. Click Add.

Safari isn't supported yet.

One-click install is on its way. We've sent it to the Chrome Web Store for review. Already installed it by hand? You can switch when the store version is live.

Questions

How do you decide?
Right now we show one thing: whether the company is a Certified B Corp, checked by hand against the B Lab directory, with the date. B Corps are independently assessed on how they treat workers, communities and the environment. It's about the company, not any single product.
Which brands are on the list?
Just H&M for now, checked by hand. We're adding more before Black Friday. A brand we haven't checked shows as “not on our list yet”, which never means naughty.
Does it track me?
No. It only runs on H&M’s shop, and the check happens inside the extension, so nothing you browse leaves your browser. There's no account. [Swap for version A in copy.md if the build calls our API.] Privacy notice.
